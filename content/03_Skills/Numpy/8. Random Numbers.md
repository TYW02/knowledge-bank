title: Random Numbers
---
Firstly you need to create a generator.
```python
rng = np.random.default_rng(seed=1)
```

## Generate number from 1-6
```python
print(rng.integers(low = 1, high = 7, size = 3))
# 1, 5, 4

print(rng.integers(low = 1, high = 101, size = (3, 2)))
# [[64, 12, 69],
#  [75, 94, 16]]
```

# Shuffling
```python
fruits = np.array(['Apple', 'Orange', 'Banana', 'Coconut', 'Pineapple'])
fruits = rng.choice(fruits, size = (3, 3))
print(fruits)

# [['Apple' ,'Banana' 'Apple'],
#  ['Coconut', 'Pineapple', 'Orange]]
```
