title: 1. Numpy Array
---
The array in numpy as different from a standard python list

It allows you to do [vectorized operations](https://www.geeksforgeeks.org/python/vectorization-in-python/):
```python
array = np.array([1, 2, 3, 4])
array = array * 2

print(array)
# [2 4 6 8]
```

### But with standard python
```python
array = [1, 2, 3]
array = array * 2

print(array)
# [1, 2, 3, 1, 2, 3]
```

# What is vectorized operations ?
Perform operations on entire arrays at once instead of iterating through elements using Python loops.
