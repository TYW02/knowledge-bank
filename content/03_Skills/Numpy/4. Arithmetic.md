## Scalar Arithmetic (Single Value)
```python
array = np.array([1, 2, 3])

print(array + 1)
print(array - 2)
print(array * 3)
print(array / 4)
print(array ** 5)

# The operation is applied to every single value
```

## Vectorized Math Function
```python
array = np.array([1.01, 2.5, 3.99])

print(np.sqrt(array))
print(np.round(array))
print(np.floor(array))
print(np.ceil(array))
print(np.pi * array**2)
```

## Element-wise Arithmetic
Does not only have to be array to array
Can be:
- Array & Scalar
- Array & Python List/Tuple
- [[5. Broadcasting | Broadcasting]]
```python
array1 = np.array([1, 2, 3])
array2 = np.array([4, 5, 6])

print(array1 + array2)
print(array1 - array2)
print(array1 * array2)
print(array1 / array2)
print(array1 ** array2)

# Each element of the array is applied the math function
```

## Comparison Operators
```python
scores = np.array([91, 55, 100, 73, 82, 64])

# IF score is < 60, change it to 0
scores[scores < 60] = 0
print(scores)
# [91, 0, 100, 73, 82, 64]

# Returns boolean array 
print(scores < 60)
# [False, True, False, False, False, False]
```
