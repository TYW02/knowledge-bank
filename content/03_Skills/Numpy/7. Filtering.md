# What does it do ?
Selecting elements from array that match a given condition

### Example array
```python
ages = np.array([[21, 17, 19, 20, 16, 30, 18, 65],
                 [39, 22, 15, 99, 18, 19, 20, 21]])
```


## Filtering for ages below 18
#Boolean_Indexing
> [!Code Example]-
> ```python
> teenages = ages[ages < 18]
> # [17, 16, 15]
> ```

This will return a flat array back to you. It will not keep the same shape as your original array.

## Using multiple filters
Filter ages older than or equal 18 AND below 65
> [!Code Example]-
> ```python
> adults = ages[(ages >= 18) & (ages < 65)]
># [21 19 20 30 18 39 22 18 19 20 21]
># NOTE: Only for and you have to use '&' for or you can use '|' 
> ```


### How to preserve shape of original array
Use `np.where()`
```python
# Syntax
np.where(condition, array, fill_value)
```

Filter for adults who are at least 18 years old and replace those that aren't with 0
> [!Code Example]-
> ```python
> adults = np.where(ages >= 18, ages, 0)
> ```
