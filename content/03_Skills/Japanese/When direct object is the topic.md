
## Vocabulary

1. 日本語 【に・ほん・ご】 - Japanese (language) 
2. 習う 【なら・う】 (u-verb) - to learn


Direct object particle is different from particle related to location in that you cannot use any other particle at the same time.

For Example:
You might have guessed that you can say そは to express a direct object that is also the topic but this is not the case.

A topic can be a direct object without using the そ particle. In fact, putting the そ particle in will make it wrong.

Example:
1. 日本語を習う。Learn Japanese. 
2. 日本語は、習う。About Japanese, (will) learn it.

日本語をは、習う。(This is ==incorrect==.)
