
> Ability to change the lowest-level physical storage structure or internal schema without affecting the higher-level conceptual or logical schemas and application programs.

- Change the physical characteristics without affecting the conceptual level
	- Modify the physical schema
	- Data is stored on disk or magnetic tapes
	- Changes to compression techniques or hashing algorithms


### Common Example
- Moving database from HDD to SSD
- Adding or modifying index or hashing algorithms to speed up data retrieval
- Changing file organization or data structure used at disk level
- Relocating database files to a different storage drive or directory path.
