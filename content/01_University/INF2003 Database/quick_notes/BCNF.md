
## Application

> [!question] Given R(A,B,C,D), F = { A → BC, C → D }:

- A -> BC: $A^{+} = \{A, B, C, D\}$, **all attributes**, so A **IS** a superkey (Satisfies BCNF)
- C -> D: $C^{+} = \{C, D\}$, it **DOES NOT reach** A or B, so C is **NOT a superkey** (Violates BCNF)

> [!success] Answer: D
