
## Domain Constraints
- **Restrict** the kind of attribute or values a column can hold in database table
- Think of it as **typed**


## Key Constraints
- Only **1** Primary key
	- Unique: no 2 tuple can have identical values for key attributes
	- Not NULL: key attribute can not have NULL values


## Referential Constraints
- Reference from **1 table to another table** must be **valid**
	- Foreign key must have **matching primary key**
	- Reference key element **must exist** in the table
