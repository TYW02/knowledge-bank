# Cone of Uncertainty
> [!question] In the Cone of Uncertainty example, which is the **earliest appropriate time** to make a detailed cost estimate?
> - [ ] A. At the start of the requirements workflow
> - [ ] B. At the end of the requirements workflow
> - [ ] C. At the end of the analysis workflow (after specifications are complete)
> - [ ] D. After the code is written
> > [!Answer]-
> > - C
> > **Estimates narrow** as **information grows**, but waiting until the code is written is **far too late** to be useful for planning.
