## Structural vs Behavioral Design Pattern
- **Structural** focus on HOW classes and objects are **composed** to build **larger, flexible structures**.

- **Behavioral** focus on HOW objects **communicate**, **collaborate**, and **distribute responsibilities** at runtime



## Patterns
A ride-hailing app must let the fare module switch between distance-based, time-based and surge pricing at run time, without changing the code that asks for a fare. Which design pattern fits best?

> [!Answer]-
> **Strategy**
> 
> Strategy swaps ways of doing 1 task


## Which C4 Level
A diagram shows a Single-Page Application, a Mobile App, an API Application and a Database, with the calls between them, all inside one system boundary. Which C4 level is this?

> [!Answer]-
> **Container**
> 
> Containers are the runnable or deployable parts inside the system



## CI/CD
A team integrates once, a week before the deadline, and then spends days fixing conflicts. Which practices from the lecture address this? (Select all that apply)

> [!Answer]-
> - Run an automated build and tests on every integration
> - Commit small changes frequently so that branches diverge less
> 
> - If you can generate something(bin files), DO NOT store it in the repository
