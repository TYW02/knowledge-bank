

## DAC vs MAC

|                | DAC               | MAC                       |
| -------------- | ----------------- | ------------------------- |
| Authority      | Owner sets rights | Sys Admin/OS set rights   |
| Mechanism      | Uses ACLs         | Security Labels/Clearance |
| Security Level | Lower/Flexible    | Highest/Rigid             |


## RBAC vs DAC
|            | RBAC                                | DAC                       |
| ---------- | ----------------------------------- | ------------------------- |
| Assignment | Based on job role                   | Based on owner rules      |
| Management | Centralised by admins               | Decentralised by users    |
| Principle  | Inherently supports Least Privilege | Reliant on User Diligence |


## DAC 
> DAC typically uses ACLs and Capability tables
