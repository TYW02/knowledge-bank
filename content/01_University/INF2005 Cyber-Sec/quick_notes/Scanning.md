# Passive vs Active

| Feature     | Passive Scanning          | Active Scanning                |
| ----------- | ------------------------- | ------------------------------ |
| Interaction | No packets sent to target | Direct interaction with target |
| Detection   | Target is unaware         | Activity and IP are logged     |
| Examples    | Google dorking, portal    | Port scanning, probing         |
