You can use print to find out the inner workings of the variable that you have created.

OR

You can use a feature that is built into most IDEs the debugger.
First set a breakpoint 
then run the debugger
When you are running into a line of function, use Step INTO.
and when you want to run a line of code, use Step OVER.
