Embedded C Bug Hunt

Revision quiz built from the complete defect checklist (Labs 1–6).

The quiz has 46 questions in five levels, from foundational to advanced:

  1. Foundational understanding
  2. Conceptual understanding
  3. Application
  4. Analysis & problem solving
  5. Advanced critical thinking

Calculation questions use fresh random numbers every time you start or restart. Answers are locked once submitted. You can jump to any question using the numbered boxes at the top, and the results page shows which topics to revisit.
